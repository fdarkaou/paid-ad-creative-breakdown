Paid-ad creative breakdown

What is inside a rival's Meta or TikTok ad, second by second? Paste PeekPanda reads of one or more stored ads and this page shows each ad's summary, hook notes, scene timeline, on-screen text, transcript and the reusable ingredients the analysis names, plus what the ads share. Nothing leaves your browser; this page never calls the API.

Optional: paste a report you saved earlier (CLI --format json or a --state file) to see what changed since then.

Where to get the JSON

The input comes from PeekPanda, an iOS competitor catalogue where every app has a case file of dated, stored evidence. Read one stored ad, with its transcript and analysis once they exist, using an API key (one call from your plan's daily API and MCP allowance):

curl --get 'https://api.peekpanda.com/v1/paid-ads/meta/111222333' \
  --header "Authorization: Bearer $PEEKPANDA_TOKEN" \
  --header 'x-genviral-tenancy: personal'

Paste a single response, a JSON array of them, or the file the command-line version saves. Over MCP the same read is get_ads with action get; the analysis state alone is action analysis. The get paid-ad analysis reference lists the analysis fields. The command-line version on GitHub picks a rival's live ads for you, reads the analysis state, can ask for missing analyses (--request, scope content:write), keeps a weekly diff and can post to Slack or Discord.

Analysis and transcripts are creative observations of the stored public ad, not a performance or policy claim. There is no spend or reach here. An ad without analysis has not been analysed yet; that says nothing about the ad. Image and video links are short-lived, so this page does not show them.
